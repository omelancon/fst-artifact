\section{Overview}

This document summarizes all results from the Float Self-Tagging artifact. It
includes figures that were omitted in the Float Self-Tagging paper to avoid
redundancy and save space.

Some experiments were not executed on some machines, either because the proper
tooling does not exists (such as branch prediction on an Apple M2) or because
the experiment takes too long to run (such as the heap experiment on RISC-V,
which would take several weeks).

\subsection{Adding a Machine to this Document}

To include results from a new machine in this summary:

\begin{enumerate}[leftmargin=4em]
    \item generate figures with \texttt{scripts/plot.sh}.\footnote{to generate
    plots for another machine use \texttt{FST\_HOST=[name] scripts/plot.sh},
    where \texttt{[name]} is the output of \texttt{uname -n} on the target machine.}
    \item update the \texttt{\textbackslash machineslist} macro in \texttt{summary.tex}.
    \item regenerate this pdf from \texttt{summary.tex}.
\end{enumerate}
